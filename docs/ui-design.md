# 界面设计配置

## 管理页面顶部标题

- 主栏目列表页仅显示栏目名，例如 `同步任务`、`连接管理`。
- 从栏目进入创建、编辑或详情页时，统一显示 `栏目名 / 当前页`。当前页面只写简短名称，不重复栏目名。
- 同步任务：`同步任务 / 新建任务`、`同步任务 / 编辑任务`、`同步任务 / {任务名称}`。
- 连接管理：`连接管理 / 新建连接`、`连接管理 / 编辑连接`。
- 后续新增管理栏目也遵循同一格式。栏目名集中定义；页面调用共用标题组件，不在各页拼接整段标题。
- 标题中的上一级栏目可点击，点击后直接返回该栏目的列表页；与侧边栏进入该栏目使用同一导航行为。当前页标题不可点击。键盘可以聚焦并用 Enter 或空格触发返回。
- 父级标题和分隔符使用次要文字色，当前页使用主文字色；字号和行高保持一致。长名称截断，避免挤压右侧操作或使顶部高度跳动。
- 顶部不加介绍性副标题，也不在内容区重复整段页面标题。表单字段帮助文字只用于解释实际操作。
- 标题与正文的间距由标题栏自身的留白提供；正文容器不再叠加顶部内边距，桌面、平板和手机布局保持一致。

首次初始化和登录页不属于管理页面，不显示栏目层级。

## 列表表格

- 连接管理使用共用表格组件，按“连接名称、部署类型、连接地址、操作”分列展示；操作列保留编辑和删除，哨兵连接显示 Sentinel 地址。
- 连接表格上方提供搜索框，按连接名称、部署类型（中文或英文）和展示的地址即时筛选，忽略大小写及首尾空格。清空搜索恢复完整列表，无匹配时显示专用空状态；编辑返回和删除后保留搜索条件，输入时保持焦点。
- 表格统一使用浅色表头、行分隔线和悬停反馈。长名称与地址允许换行；空列表保留表头并显示空状态。
- 窄屏保持表格结构和字号，通过表格容器内部横向滚动查看完整列；滚动容器支持键盘聚焦，不能撑宽整个页面。

## 字号与可读性

- 默认正文、输入框、按钮及桌面导航使用 16px；表单标签、辅助说明、步骤和日志使用至少 14px。状态徽标使用 13px，手机底部导航和步骤使用至少 12px。
- 字号使用相对于浏览器默认字号的 `rem`，正文行高为 1.5；窄屏允许内容自然换行，不能通过缩小正文和表单字号来容纳内容。

## 表单操作与下拉选择

- 新建任务时，任务名称默认使用浏览器本地时间生成，格式为 `Redis Sync yyyymmddhhmm`（例如 `Redis Sync 202609281100`），允许手动修改；向导切换步骤和编辑已有任务时保留原名称。
- 新建连接时，连接名称按同样的本地时间规则生成，格式为 `Redis Connection yyyymmddhhmm`（例如 `Redis Connection 202609281100`），允许手动修改；切换部署类型、测试连接和编辑已有连接时保留原名称。
- 连接和任务的新建、编辑表单统一使用单列纵向布局，每个字段独占一行；部署类型切换后显示的字段和任务筛选规则也遵循这一排列，不保留双列布局的空占位。
- 新建和编辑表单的主要操作区位于页面内容底部，并在内容面板内水平居中。内容较短时，操作区贴近内容面板底边；内容较长时，随表单自然下移，不遮挡字段。
- 连接表单中的“测试连接、保存连接”以及任务向导中的上一步、继续、预检和启动操作使用这一布局。任务向导不提供“保存草稿”按钮。
- 管理页面的下拉选择统一使用项目组件的触发框、选项面板、悬停和选中样式；保留键盘操作、字段标签和表单取值。新增下拉字段继续复用同一组件。
- 下拉框和选项不使用按钮按压时的缩放动画，点击、展开和收起时保持控件的位置与尺寸稳定。焦点切换不滚动页面，键盘定位选项时只滚动下拉列表。

## 连接认证

- Redis 与 Sentinel 各自提供认证方式下拉框：无认证、仅密码、仅账号（无密码）、账号和密码。只显示需要的用户名或密码字段，保持单列布局，切换选项不丢失未提交的输入。
- 认证方式下拉框下方不显示描述文字。
- 编辑已保存密码时显示留空保留的提示，切换到无密码方式可明确清除；测试连接不保存认证方式或密码修改。

## 提示弹窗

- 成功提示和错误提示统一由共用弹窗组件展示；错误弹窗直接突出具体错误，不显示“操作未完成”等泛化标题或居中的感叹号。内容与底部确认按钮保持居中，右上角提供关闭按钮。弹窗保持紧凑，仅底部操作区用细线分隔，不使用顶部标题栏或悬浮按钮。
